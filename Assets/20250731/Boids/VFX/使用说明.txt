Boids VFX：Unity 2022.3 / VFX Graph 14.0.12

先运行
1. 把本目录 BoidsDemo.prefab 拖入场景，放在世界原点附近。
2. 让摄像机看向原点附近约 24 米宽的地面区域，进入 Play Mode。
3. 在 Boids VFX Simulation 组件上调节 Alignment、Cohesion、Separation。
   默认 256 个粒子。示例用普通粒子展示模拟，尚未替换为 VAT 角色。
4. 双击 BoidsDemo.vfx，可以看到接好线的 Boids - Apply GPU State 节点。
   若示例资产未生成：Tools > Boids VFX > Create Demo Assets。

接到自己的 VAT 图
1. Blackboard 新建并公开 GraphicsBuffer：BoidsState；Unsigned Integer：BoidsCount。
   名称和大小写必须一致，组件通过这些名称绑定数据。
2. Spawn 使用一次 Single Burst，Count 接 BoidsCount。去掉 Constant Spawn Rate。
3. Initialize 的 Capacity 至少 2048，模拟空间选 World。
4. 在 Initialize 和 Update 中各添加 Boids - Apply GPU State（分类 Boids）。
   把 BoidsState 连到两个节点的 State 输入。节点放在其他位置设置块之后。
5. Update：Integration / Update Position 选 None / 关闭；
   Angular Integration 选 None；关闭 Age Particles 和 Reap Particles。
   删除其他会修改 position / velocity / angleY 的移动块。
6. 在同一个 Visual Effect GameObject 上添加 Boids VFX Simulation。
   Compute Shader 可留空，组件会加载 Resources/BoidsSimulation.compute。
7. 保留你的 VAT Mesh、材质和动画连接。模型本地前向按 +Z 处理；
   如果模型轴向不同，在输出层额外补旋转，不要让模拟再计算一次位置。
8. 根据角色实际 velocity 的长度调整 VAT 步频；本组件不负责 VAT 帧号或待机切换。
9. 扩大 Initialize Bounds，覆盖整个模拟范围。示例 Bounds 为 60×20×60，
   若移动物体或扩大 Arena Radius，要同步调整图的包围盒，避免被剔除。

重要约定
- 本例为 XZ 地面群集，地面 Y = 组件 Transform 的世界 Y。
- 运行时粒子数固定，每次 Reset Simulation / Reinit 后只生成一批。
- 节点用 particleId 对应模拟编号。因此不要重复 Play 事件追加粒子、自动死亡重生、
  加 GPU Spawn 或把其他发射器混入同一个系统。重启请用组件 Reset Boids Simulation。
- 改 Agent Count 会重置模拟；范围 1～2048，Graph Capacity 也需要足够。
- 需要 Play Mode；图窗口单独预览时没有组件提供 Buffer，不会出现模拟结果。
- 暂停 VisualEffect.pause 时也暂停模拟。视觉裁剪不会停止这份外部模拟。
- 圆形 Arena 仅用于把群体保持在演示范围，不包含墙体、SDF 或 NavMesh 避障。
- Separation 不保证零穿插；基础 Boids 不等于 ORCA。

按这个顺序读代码
1. Resources/BoidsSimulation.compute：一个线程负责一个角色。
   从 _Read 读取全部旧状态，遍历 j 查距离，累计分离 / 对齐 / 聚合，
   限制加速度与速度，将新状态写入 _Write。重合角色也有确定的反向分离。
2. BoidsVFXSimulation.cs：创建初始状态 → Dispatch → 交换读写 Buffer → 绑定 VFX。
   每个角色占两个 float4（32 字节）：位置+朝向，以及速度。
   每步只交换 GPU 引用，不做 CPU 粒子位置回读。
3. Editor/BoidsApplyState.cs：VFX 自定义 Block。
   使用 particleId*2 取位置，particleId*2+1 取速度，然后写入 VFX 属性。
   它是模拟结果的入口节点，Boids 邻居计算发生在配套 Compute Shader 中。
4. Editor/Unity.VisualEffectGraph.Editor.asmref：沿用项目 CrowdSDF 的扩展方式，
   编译进 VFX 编辑器程序集以访问 VFX 14 的内部节点 API。升级 VFX 包时需要复核。

验证
Tools > Boids VFX > Validate GPU Simulation：GPU 上验证分离、重合、聚合、对齐，
以及 65 个角色的 600 步模拟（覆盖线程组尾部、地面、边界、速度与有限值）。
结果写入 Verification.txt。测试回读仅用于验证，正常运行不回读。

性能范围
这是用于学习与少量群体的全量遍历版本，复杂度 O(N²)。
2048 是输入保护上限，不是性能保证。大规模 Crowd 应把邻居遍历换成空间网格。
前后双缓冲与 VFX 节点接口可以保持不变。
