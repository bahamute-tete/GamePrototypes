# Fog Timeline 使用说明

适用：Unity 2022.3 / Timeline 1.7。控制 Unity RenderSettings 全局雾，材质需要支持该雾效果。

## 基本使用

1. 添加 `Custom/Fog/Fog Track`，无需绑定对象。
2. 选中轨道，设置雾模式。默认“跟随场景”，兼容旧片段。
3. 添加 Fog Clip。在非预览、非播放状态下，新片段自动读取当前活动场景的雾参数；复制片段保留原参数。
4. 选中片段调整颜色，以及当前模式对应的距离或密度。可用“读取当前场景雾”捕获场景设置，支持撤销。
5. 拖动片段两端的淡入淡出手柄控制过渡，两个片段交叠时自动混合。拉宽片段可看到参数摘要，底部颜色条显示目标颜色，悬停也可查看参数。

读取场景按钮只读取颜色、距离、密度，不改变轨道模式。预览中点击会读取当前预览效果，Inspector 会提示。场景雾关闭时仍读取其参数；片段生效时会启用雾。

## 过渡及恢复

- 总片段权重不足 1 时，剩余贡献来自接管前的场景原始参数；不会再抵消单片段的淡入淡出权重。
- 原场景无雾：指数雾从零密度进入；指数平方雾按光学厚度过渡；线性雾通过扩展终点距离逐渐进入。这不是额外的 Shader 雾强度通道，线性模式在非常远处的观感会与强度淡入有所不同。
- 暂停保留当前画面。片段空档、PlayableDirector.Stop（销毁播放图）、退出 Timeline 预览和脚本重载时恢复原始参数。
- 直接调用 `playableGraph.Stop()` 仅暂停图，不销毁图，因此保留效果。程序结束控制时应调用 Director.Stop 或销毁图。
- 空档后重新接管会重新读取场景基准，允许空档中其他系统更新场景雾。
- 多轨道或多 Director 同时生效时，先取得控制权的 Mixer 生效，其余提示一次冲突并暂不写入。请将需要混合的片段放在同一轨道。
- 固定轨道模式与原场景模式不同时，进入片段会切换算法；不同算法之间无法仅靠这些参数保证视觉连续。需要平滑进入时，保持场景与轨道模式一致。

旧的四个脚本名称、片段序列化字段和原有脚本 GUID 保留。新增编辑器代码位于 Editor 文件夹，不参与玩家构建。

## Unity 中验收

1. 单个片段设置淡入/淡出，检查密度或距离逐步变化；退出预览核对原始设置。
2. 两片段交叠，来回拖动指针，检查颜色与参数连续变化。
3. 场景原始雾分别开启/关闭，测试三种模式的片段进入和离开。
4. 暂停保持画面；停止、空档、禁用 Director、退出预览后恢复；重复播放不累积状态。
5. 读取场景后撤销/重做；复制片段保留参数；旧 Timeline 的参数不丢失。
6. 同时播放两条轨道，确认冲突提示及未接管的轨道不会覆盖/恢复另一条轨道的状态。
