# 第二阶段：有符号距离场

仅修改 PlaneContactSnapshots 独立目录。原 PlaneContact 脚本、Shader、场景和材质保持不变。

## 检查方法

打开 Demo/ContactSdfDemo.unity，选中 `SDF Snapshot — inspect view modes`，点击“手动捕获当前轮廓”。默认关闭编辑自动预览，捕获结果会冻结，方便检查。

组件新增：

- Generate Sdf：捕获时生成 SDF，关闭则回到只保存 R/G。
- Sdf Resolution：默认 256；调高后需重新捕获，旧快照的数据不会变化。
- View = Original Mask：原 R/G 轮廓。
- View = Filled Section：蓝色为截面内部，黑色为外部，白色为边界。
- View = Signed Distance：内部蓝色、外部橙色，色带间隔 0.1 米。
- View = Offset Contour：蓝线为固定正距离等值线，灰线为原轮廓。
- Preview Distance：等值线距原轮廓的米数。不是缩放系数，也不会随时间自动增大。
- Preview Line Width：检查用等值线的总宽度，单位米。

该演示副本将原平面显示关闭，并将角色放到演示相机不渲染的层，以便完整查看截面；角色网格仍参与计算。原演示不受影响。SDF 纹理为临时资源，不保存进场景，重新打开后请重新捕获。

## 数据链与算法

捕获当前姿态 → 三角形和平面交线 → 扫描线奇偶填充 → 两次二维平方欧氏距离变换 → 米制 RFloat SDF → 绑定当前快照。

没有从柔光 G 反推距离。为了不改原组件，新生成器只在捕获时独立读取网格；蒙皮需要额外 BakeMesh。三角形求交复用原组件公开的静态 IntersectTriangle 方法。

单个 Renderer 内采用奇偶填充，可以处理独立轮廓和嵌套孔洞。不同 Renderer 的填充取并集。同一 Renderer 内互相重叠的实体壳体可能按奇偶规则相消；复杂模型建议使用闭合接触代理或拆分 Renderer。本版不进行完整流形拓扑验证。

距离变换分别寻找最近内部和外部像素。横纵权重使用平面实际宽高，非正方形平面不会把米制距离拉伸。最终 RFloat：内部负、边界约零、外部正。它是栅格近似，误差约一个像素，不是解析三角形距离；细于一个像素的孔洞可能丢失。

出现奇数扫描线交点、不可读网格、截线触及平面范围边缘或没有可分辨填充时，报告原因并退回该次普通 R/G 快照。不存在的或不可靠的 SDF 不会被作为有效距离场显示。奇数交点检查能发现部分开口，但不能证明任意输入一定闭合。

## 性能与下一阶段

这是 CPU 验证实现，默认只在捕获时执行，不是每帧生成。角色演示 256 分辨率捕获实测约 7～13 ms（编辑器、单机结果，不是 VR 性能承诺）。Inspector 显示最近一次耗时。可以先关闭自动预览，使用手动捕获；正式性能优化尚未完成。

每张 256×256 RFloat GPU 数据约 256 KiB，且保留 CPU 可读副本供检查；现有 R/G 快照仍保留。所有临时资源随组件关闭释放。

已验证矩形内外符号、横纵米制距离、角点距离、嵌套孔洞、快照不变、范围越界拒绝，以及真实角色三种视图。尚未实现按年龄动态外扩。下一阶段只需让等值线目标距离使用 `speed * age`，并接入波纹颜色、宽度及寿命。
